Holidays Tracker Database (SQL Practice)
A personal relational database designed to track all details of my past holidays, including destinations, accommodations, activities, meals, and costs — day by day.

🔹 Key Features:

Created structured tables for countries, locations, accommodations, activities, meals, and daily expenses.

Designed relationships between tables to reflect real-world travel experiences.

Wrote SQL queries to extract insights, such as total cost per trip and daily spend breakdown.

Practiced logic design, filtering, grouping, and joins to simulate real reporting and budgeting use cases.
